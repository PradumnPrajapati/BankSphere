Architecture & Core Implementation

How Bank Sphere pairs C++ DSA with modern dashboarding

C++ BST Data Structure

Binary Search Tree Account Ledger

Organizes customer accounts keyed on unique Account Numbers with O(log N) insertion, search, and deletion capabilities. Changes are persisted on every mutation to data/accounts.txt.

AuthTable Module

Separate Chaining Hash Table

Features 13 fixed buckets with linked lists resolving collisions. Salted password hashing (FinTrack@<password>) ensures credential security without storing plain text in memory.

Audit System

Atomic Transaction Logs

Individual account logs recorded in data/transactions/<acc>.txt with timestamped records for transfers, withdrawals, and deposits.
